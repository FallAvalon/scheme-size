# Телепорт 0.4.1 — повторяемые проверки

Observer запускает настоящий desktop 160.7 в отдельных профилях workspace-*, посылает синтетические события Arc и устанавливает поля координат SDL pointer через reflection. Физическое нажатие боковой кнопки и реальная сеть этим проходом не доказываются. Установленный профиль не используется.

После сборки, из корня:

```powershell
./validation/teleport041/Run.ps1 -DesktopJar C:/path/to/non-steam-desktop-160.7.jar -JdkHome C:/path/to/full-jdk -GameJava C:/path/to/runtime/bin/java.exe -UiScale 100
```

Plus, God и совместная загрузка проверены последовательно при 100%. Есть проверки Alt+Mouse Back, обычной кнопки без Alt, удержания, координат игрока/юнита, скорости, UI/модального окна/ввода текста/отключённого модуля. Отказ удалённому клиенту проверен переключением Net.active/server в observer без настоящего подключения; поля восстановлены до продолжения. NaN и выход из карты проверяются через HostActions. Остальные сценарии унаследованы из ui040.

Предыдущий проход завершился на проверке попадания тестового указателя в панель: фиксированные координаты оказались вне сжавшейся панели. Observer исправлен на координаты настоящей кнопки рейки; это не исправление кода мода. Первая сборка выявила отсутствие keybind-перевода, затем оба перевода добавлены; финальные check/assemble прошли.

Ручная проверка: Alt + боковая «Назад» над свободным участком карты; затем удержание, чат/меню и настройки переназначения. Переназначение средней/боковых кнопок реализовано, физическая проверка этого диалога пока не пройдена.
