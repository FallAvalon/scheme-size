# ТЗ № 2: матрица реализации O279

Срез 0.4.2 — [№ 20](20_fast_map_controls.md): общее исправление zoom/быстрых подтверждений и клиентский телепорт; God получает прямой доступ к природным стенам и отмене. Статусы полного O279 не повышаются этим UI-срезом.

Пользовательское расширение 0.4.1, Plus **и** God: Alt + Mouse Back — телепорт своего игрока под курсор с авторитетной проверкой хоста; [отчёт № 19](19_cursor_teleport.md). Новая функция не объявляется исходным O279 и не повышает его статусы.

Интерфейс 0.4.0: выровненные разделы, карточки схем/юнитов, шаги создания, отмена выбора места — [отчёт № 18](18_concept_interface.md). Windows Plus/God 100%/200% проверены событиями Arc; это не повышает статусы полного паритета O279.

Публикация 04.11.2026: Size Plus (S+) / Size God (SG), версия 0.3.1 — [отчёт № 17](17_github_publication.md). Изменены названия, иконки и упаковка; статусы функционального паритета этим не повышаются.

Последнее дополнение: [№ 16](16_roster_icon_publication.md) — группы по командам/типам, общая иконка и подготовка двух витрин, версия 0.3.0. Статусы остальных строк O279 не повышались.

Предыдущее дополнение: [№ 15](15_unit_death_and_player_ui.md) — исправление действий игрока, выбор нескольких юнитов и native массовая смерть с защитой игрока. Точные реально пройденные проверки перечислены отдельно; остальные статусы O279 не повышались.

Предыдущая приёмка: [№ 14](14_ui_and_god_replacement.md) — компактные арена/обзор/настройки, привязки, статус маршрутов и замена занятых объектов в God с native восстановлением. Исторические результаты ниже не выдаются за полный паритет.

04.11.2026: исправлены оставшиеся панели строительства/ресурсов/создания юнитов; God получает отдельную host-политику спавна/ресурсов и мгновенную кисть. Иконки, точные Windows/vanilla-проверки и технические границы — [отчёт № 13](13_god_controls_and_ui.md). Это не заменяет статусы исходного паритета ниже.

Исправление по пользовательским кадрам: обрезание в схемах, слоях и игроках и избыточный текст устранены в новой компактной колонке; добавлена справка «?» — [отчёт № 12](12_ui_compact_help.md). Исторические результаты ниже сохранены.

Навигация обновлена 03.11.2026: общий немодальный workspace Plus/God, прямые категории God, выбор на карте и расширенные параметры — [отчёт № 11](11_ui_navigation.md). Существующие пофункциональные статусы ниже сохранены; новый UI-проход не доказывает автоматически каждую строку O279.

Колонки Plus/God задают принадлежность, а не готовность. По уточнению пользователя от 02.11.2026 весь O279 относится к обеим редакциям, включая исходные административные инструменты; отдельные организаторские сценарии God перечислены ниже. Общий прогноз маршрутов также обязателен для обеих редакций.

## Журналы и значение статусов

«Реализовано» означает наличие пользовательского пути, а проверка ограничена названным сценарием. Ни одна строка не помечается полным `verified` для O279. L — [локальные игровые сценарии](../work/ui-probe/run-fc14af779f3d457992e4f8a015d2c6d8/stdout.log); N — [host/vanilla/reconnect](../work/net-probe/run-6a6984c2ff164b06a05fc9c9ac2e8fc2/guest/stdout.log); M — [kick/ban/admin/trace](../work/net-probe/run-2f84c5b8860b431c89095e1366484d4a/guest/stdout.log); C — [локальный relay](../work/net-probe/run-d1650219816d4af7a2402a6d498a6033/guest/stdout.log); P — [обмен метаданными](../work/net-probe/run-ac1caf37bf2e4d99ba18ee8288012fcf/guest/stdout.log); E — [редактор и native импорт](../work/ui-probe/run-7832ddfcbbb843d883137f2856b0aa6e/stdout.log). Свежие расширенные проверки и неудачные попытки перечислены в [отчёте № 7](07_validation_and_remaining.md).

Код перечисленных классов находится в [общем дереве](../mod/src/main/java/org/schemetools/); UI — `client`, авторитетные действия — `host`, схемы — `schematic`, босс/пресеты — `event`. Android/mobilebuttons и Backdoor исключены требованиями пользователя. Внешние ограничения и повторяемые шаги — [план № 6](06_external_test_plan.md). Отсутствие Linux/WAN не делает автоматически проверенными Windows-сценарии.

## Критерий завершения

Паритет не объявлен. Реальные внешние блокеры: Linux runtime, WAN/NAT/второй ПК, внешний CLaJ relay, опубликованный канал обновлений и совместимый backend. Отдельно остаются непроверенные локальные UX/clipboard/file chooser/долгая нагрузка/редкие игровые комбинации; они перечислены как непроверенные, а не спрятаны под внешними блокерами. Для выпуска нужен результат каждой обязательной строки и проверка допустимых замен по ТЗ № 2.
