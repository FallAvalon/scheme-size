# Size Plus (S+) и Size God (SG) — тестовые сборки

Публикация: [версии 0.4.0 и проверки](../reports/18_concept_interface.md).

Русское руководство: [USER_GUIDE_RU.md](USER_GUIDE_RU.md). Последние изменения и проверки: [отчёт № 7](../reports/07_validation_and_remaining.md), внешние тесты: [план № 6](../reports/06_external_test_plan.md).

Исправленные расхождения и короткий пользовательский проход: [приёмочный аудит № 9](../reports/09_user_acceptance.md). Для отдельного профиля из корня проекта: `./work/user-acceptance.ps1 -Edition god` (либо `plus`, `both`, `vanilla`). Это обычные JAR без observer-модов; новый профиль создаётся внутри `work/`.

Обе редакции используют общую кодовую базу. Plus содержит общие инструменты, в том числе локальный прогноз маршрутов противников; God добавляет инструменты организатора и режим «Босс-игрок». Полный паритет с Scheme-Size 2.7.79 и критерии ТЗ № 2 пока **не выполнены**. Для проверки используйте отдельный профиль и тестовый мир.

Для сборки нужны JDK 17 или новее и `desktop.jar` Mindustry 160.7. Сборка компилирует код под Java 17 и не включает файлы игры. При первом запуске Gradle wrapper требуется сеть.

Windows, из каталога `mod`:

```powershell
./gradlew.bat check assemble '-PmindustryJar=C:\path\to\desktop.jar'
```

Linux, из каталога `mod`:

```sh
sh ./gradlew check assemble -PmindustryJar=/path/to/desktop.jar
```

Результаты находятся в `build/libs/scheme-size-plus.jar` и `build/libs/scheme-size-god.jar`. Linux-команда приведена для воспроизведения, но в текущей среде Linux не проверена. Публичный тестовый выпуск 0.4.0 не означает завершение полного ТЗ. Три варианта загрузки — Plus, God и обе редакции вместе — проверены только в изолированной копии Windows-игры; совместимость со сторонними модами и полное поведение обеих редакций не проверены.

Для тестовой установки импортируйте нужный JAR штатным менеджером модов игры и перезапустите игру. Для удаления отключите и удалите мод через тот же менеджер и перезапустите игру; отдельно созданные схемы и пресеты могут оставаться в тестовом профиле. Не удаляйте сохранения и настройки основного профиля. Модификация установлена у ведущего, а другие игроки могут подключаться ванильным клиентом для тех действий, которые проверены в сетевых сценариях.

Текущий статус каждой функции и её ограничения: [матрица O279](../reports/02_o279_implementation_matrix.md), [проверки](../reports/03_runtime_checks.md), [редакции и маршруты](../reports/04_editions_and_routes.md). Команды игровых проверок приведены в отчёте. Прогноз маршрутов является локальной оценкой по клеткам, а не гарантией точного пути игрового AI.
