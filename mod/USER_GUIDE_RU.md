# Size Plus (S+) и Size God (SG): руководство

Цель — настольная Mindustry V8 **160.7**, Java 17+. Текущая версия `0.4.0` остаётся разработкой: полный паритет O279 ещё не подтверждён. Статус каждого пункта — в [матрице](../reports/02_o279_implementation_matrix.md), последние проверки — в [отчёте № 7](../reports/07_validation_and_remaining.md). Android/macOS не заявлены. Linux пока не запускался в доступной среде.

Сборки подготовлены к пользовательской приёмке на Windows с оговорками: [короткие шаги, исправленные расхождения и расположение логов](../reports/09_user_acceptance.md).

## Новый интерфейс 0.4.0

- Нажмите S+/SG над списком разделов, чтобы свернуть или вернуть подписи. На узком окне подписи автоматически заменяются подсказками по наведению; настройка сохраняется.
- Схемы → Библиотека: выберите карточку с настоящим превью → Разместить на карте. «С карты» и «Выделить» захватывают участок; «Сохранить копию» спрашивает имя. Импорт и расширенные инструменты сохранены.
- Юниты → На карте: команда → типы → красная кнопка с названием и количеством целей. Пустой выбор остаётся пустым. Рамка и индивидуальный список сохранены.
- Юниты → Создать: команда, тип по иконке, количество, «Место на карте». Другие команды раскрываются отдельной кнопкой. Количество меняется полем, +/− или быстрыми 1/10/50.
- Предпросмотр показывает точку и тип с количеством; он не обещает расположить группу сеткой. Место появления окончательно проверяет хост/движок. ЛКМ выбирает точку и открывает подтверждение; ПКМ, Esc или «Отмена» закрывают выбор без создания. При отмене с зажатой кнопкой последующее отпускание не создаёт юнитов.
- Поля и фильтры сохраняются при переключении разделов/масштаба. Большие списки и панели при 200% прокручиваются; все действия одновременно на маленьком экране не помещаются.

## Установка и сборка

**Plus** содержит общие схемы, строительство, информацию, AI, исходные административные сценарии и прогноз маршрутов. **God** использует тот же код и добавляет организаторские настройки, «Босс-игрок» и пресеты. Маршруты доступны обеим редакциям. Оригинальный Scheme-Size не является зависимостью.

Сначала используйте отдельный профиль и тестовую карту. Импортируйте `scheme-size-plus.jar` либо `scheme-size-god.jar` из `mod/build/libs/` через штатный менеджер модов и перезапустите игру. Базовая совместная загрузка проверена на Windows: God предоставляет общий интерфейс без двойных обработчиков. Обычно достаточно одной редакции. Совместимость со сторонними модами не проверена полностью.

Из каталога `mod`, с полным JDK 17+:

```powershell
./gradlew.bat check assemble '-PmindustryJar=C:\path\to\desktop.jar'
```

```sh
sh ./gradlew check assemble -PmindustryJar=/path/to/desktop.jar
```

Первый запуск wrapper скачивает Gradle 9.1.0. Сборка проверяет build и не включает файлы игры в мод. Windows-скрипт `build-local.ps1` — запасная компиляция/упаковка обеих редакций, без полного набора тестов Gradle. Linux-команда подготовлена для воспроизведения, её успешное выполнение в этой среде не заявляется.

## Панель и хост

В схемах, слоях, игроках и маршрутах маленькая кнопка **?** справа объясняет соседнее действие. Она не выполняет его. Основные панели показывают короткие подписи; справка и технические ограничения открываются по запросу. Импорт схем раскрывается кнопкой «Импорт», редкие параметры — через «Дополнительно». [Кадры и проверки этой правки](../reports/12_ui_compact_help.md).

Слева под HUD находится компактная рейка. **S+ / SG** сворачивает и раскрывает её. Значки открывают единственную контекстную панель: схемы, строительство, маршруты, слои, арена. В God напрямую доступны игроки, ресурсы, юниты и событие. Наведите мышь на значок для подписи; если все не помещаются, прокрутите рейку. «Другие инструменты» сохраняет доступ к остальным функциям, шестерёнка — к настройкам. Кнопка X или Escape закрывает контекст, стрелка назад возвращает из дочернего инструмента. Обычная карта вне панели остаётся доступной.

«Выбрать область мышью» временно освобождает место панели. Потяните по карте, отпустите для предварительного просмотра; Enter / «Выбрать» подтверждает, Escape / правая кнопка отменяет. Выделение само по себе мир не меняет. Для зданий «Использовать» включает штатный preview схемы; для ландшафта «Указать место на карте» выбирает точку и затем требует подтверждения пакетов. В God можно указать игрока, ядро и место создания юнитов на карте. Для игрока выбирается ближайший в пределах пяти клеток, для ядра требуется клетка настоящего ядра. «Дополнительно» открывает точные координаты и редкие операции. Поиск, выбранная схема, тип юнита и введённые значения сохраняются между закрытиями в текущем мире; смена мира сбрасывает привязанные к нему инструменты.

В меню игры также есть категория мода в настройках. Можно выключать модули, сдвигать рейку и назначать клавиши с Ctrl/Alt/Shift. По умолчанию они не назначены. Набор основных клавиш O279 предлагает F12, Y, G, F7, I, F2, F3, F4; ознакомьтесь с конфликтами. Штатные привязки автоматически не удаляются. Ввод текста и открытые модальные окна подавляют игровые привязки мода. Новый интерфейс и границы проверки ввода описаны в [отчёте № 11](../reports/11_ui_navigation.md).

Для встроенного хоста начните игру и штатно откройте сервер. Ванильные гости подключаются по IP/Steam и не устанавливают мод для проверенных игровых действий. На чужом сервере хостовые операции недоступны даже при admin; используйте штатный интерфейс этого сервера. Локальные инструменты не дают дополнительных серверных прав.

Headless безопасно загружает редакции без UI. Это не предоставляет панель или dedicated-режим босса. Официальному серверу нужен полный runtime: Steam JRE в этой среде не содержит `java.logging`.

«Найти действие» в панели и настройках ищет по русским названиям среди включённых модулей текущей редакции. Кнопка показывает назначенную клавишу и открывает тот же инструмент. При отсутствии игры действия отключены. Отложенное подтверждение изменения мира отвергается после смены карты: откройте инструмент заново и проверьте цель.

God → «Настройки» → «Раскладки панели организатора»: до 16 именованных локальных профилей (формат 1). Сохраняются HUD, модули, визуальные слои и камера; применение — с подтверждением. Оно останавливает локальные фоновые задачи и выключает маршруты. Мир, активное событие, клавиши, обмен метками и distributor не меняются. Событие и наборы ресурсов имеют собственные пресеты. Отключение консоли прекращает повторяющиеся JS-задачи, отключение строительства — ожидающую замену и операцию с предметами.

Обмен peer-метками по умолчанию выключен. Он поддерживает новый протокол и bounded адаптер O279 (`SendMeSubtitle`/`MySubtitle`/`Subtitles`). Метка всегда является заявлением клиента, а не доказательством версии/личности и не источником прав. Нет ответа — неизвестно. Подпись до 80 символов, управляющие символы отвергаются, старые цвета очищаются; список и частота ограничены. Wire-совместимость проверена стендом в обе стороны; исходный бинарник O279 отдельно не проверен.

## Инструменты God после обновления 04.11.2026

В ресурсах нажмите кнопку с иконкой предмета и выберите его из сетки. Количество — изменение со знаком; наборы ресурсов также используют иконки. Применение набора не требует имени; имя нужно для сохранения.

God создаёт до 1000 юнитов за операцию, включая запрещённые и скрытые типы. Командный лимит отключается общим native правилом; это видно ванильным гостям. На непроходимой точке ищется пригодная клетка рядом, поскольку native физика иначе уничтожает юнита. Права хоста и корректность данных проверяются повторно.

God позволяет превысить обычную вместимость ядра и прежние ±10000. Переполнение int и отрицательные запасы не разрешены. Вместимость соответствующего типа ядра повышается на хосте в текущем мире; у ванильного гостя максимум может показываться стандартным. При загрузке с God вместимость восстанавливается из запасов, при reset исходные свойства контента возвращаются. После удаления God снова действуют стандартные правила.

В строительстве God по умолчанию мгновенно размещает блоки без расходов, строительного юнита, unlock/ban и условий местности. Копирование конфигурации сохранено. Кисть God использует до 4096 клеток/объектов за операцию, заменяет занятые объекты целиком; отмена восстанавливает прежние здания, настройки и запасы. Последующие изменения в затронутых объектах при такой отмене перезаписываются. Обычные очереди сохранены в «Дополнительно». Нажимайте «?» рядом с действием для объяснения. [Точные проверки и границы](../reports/13_god_controls_and_ui.md).

## Схемы, быстрый доступ и изображения

Библиотека объединяет схемы игры и независимые копии мода. Есть поиск по имени/тегу, файл/Base64, экспорт и сохранение новой копии. Экспорт не перезаписывает существующий файл. Повреждённый импорт не удаляет оригинал. До захвата выберите слой: здания, планы, пол, препятствия, overlay, весь ландшафт. Область задаётся координатами либо мышью по видимой карте; для большой области настройте камеру заранее.

`.msch` и `.mtls` содержат одинаковый msch-поток, второй используется для больших схем. Чтение/запись поддерживает 512×512. Ванильный читатель имеет меньший предел, поэтому большая `.mtls` не обещается как переносимая ванильному гостю схема. Полный штатный preview доступен и для плотных 512²; свыше 16 384 планов требуется подтверждение возможной задержки. Это порог предупреждения, а не лимит игры. Необязательные участки до 128×128 снижают нагрузку. X/Y участка — смещение внутри оригинала. Здание относится к участку с опорной клеткой, даже если край выходит наружу; размещайте участки с исходными смещениями и проверяйте связи.

Весь ландшафт до 512² вставляется автоматически пакетами до 4096 клеток раз в 300 мс. Подтверждение показывает суммарное число изменённых клеток и пакетов; статус и отмена находятся в окне схем. Перед каждым пакетом проверяются права, мир и исходные клетки. Отмена/конфликт прекращает оставшееся; уже применённые изменения остаются. Undo хранит последние 16 пакетов. Неуказанные слои сохраняются, препятствия не заменяют здания. Это не атомарная замена или полный откат всей карты.

«Быстрые схемы по тегу» сохраняет точный тег и запускает штатное размещение одним нажатием. Пустой тег показывает все подходящие схемы. Ландшафт применяется через полную библиотеку с подтверждением.

Импорт изображения принимает PNG, обычный/прогрессивный JPEG и BMP 24/32 бит: до 16 МиБ и 4096×4096 на входе, 1 048 576 пикселей на выходе. Выберите дисплей, строки/столбцы, сглаживание и шаг цвета. Прозрачность накладывается на чёрный фон. Работа идёт в фоне; закрытие окна отменяет результат. Создаются обычные дисплеи и микропроцессоры с mlog; им нужны питание и время отрисовки. При нехватке места уменьшите раскладку или упростите цвета. Доступны сохранение схемы и копирование программ.

## Строительство и арена

Строительные инструменты создают обычные планы: заливка, контур квадрата/окружности, замена и демонтаж связного участка. Блок можно выбрать либо скопировать с союзного здания вместе с поворотом/конфигурацией. Существующая очередь защищена от наложения. Восстановление возвращает планы, не содержимое зданий и затраченные ресурсы.

Обычная замена требует разрешённой игрой замены. Для несовместимых блоков одного размера есть «демонтаж и постройка»: сначала штатный демонтаж, затем заявка на свободное место. Отмена прекращает новые заявки. Динамическое изменение карты может помешать постройке после демонтажа; об отказе выводится сообщение. Проверяются зона чужого ядра и условия размещения.

Запросить/внести предмет и соединить энергоузел можно отдельными кнопками. Действуют штатные дальность, вместимость и серверные проверки. **«Уничтожить несомые предметы» безвозвратно очищает инвентарь юнита** штатным сбросом: предметы не остаются на земле. Подтверждение показывает вид и количество; изменение тела или инвентаря отменяет действие.

«Забрать и уничтожить лишние предметы» выбирает песок, затем уголь, иначе первый доступный предмет хранилища. Нужен пустой инвентарь. Предпросмотр показывает точное количество и источник; после подтверждения ожидается штатная передача, затем выполняется уничтожение. До 5 секунд ожидания можно отменить отдельной кнопкой. Полученные до отмены предметы остаются у юнита. Смена мира, тела, прав, дальности или несоответствие предмета отменяют ожидание. Обычные действия с предметами блокируются на время ожидания. На удалённом сервере окончательное решение принимает штатный серверный API; проверяйте итоговый запас.

Для линии к удалённой сети выберите в строительных инструментах автоматически соединяемый энергоузел и начальные X/Y. Радиус исключает ближние здания при поиске цели. Кнопка показывает ближайшее подходящее союзное здание и число узлов; после подтверждения они добавляются в обычную очередь. Поиск ограничен 50 тысячами проверенных построек и примерным временным бюджетом, чтобы не задерживать игру на очень плотных картах. Занятая клетка, изменённая цель или изолирующая стена вызывают отказ. Автосвязь зависит от соседних построек и состояния карты во время строительства: проверяйте готовую сеть.

Ландшафт: выберите область и материал, нажмите «Применить» и подтвердите. Форма, слой, координаты и отдельный расчёт находятся в «Дополнительно». До 4096 клеток и 16 отмен. Plus сохраняет защиту построек/конфликтов, God может заменить занятые объекты и принудительно вернуть native снимок при отмене.

Кисть построек: в God до 4096 объектов/клеток за операцию, включая замену занятых объектов целиком. Маленькое выделение ставит один крупный блок. В подтверждении показано число заменяемых объектов. 8 отмен возвращают прежние native данные; последующие изменения могут быть перезаписаны. В Plus сохранены обычные проверки, до 256 зданий и защищённая отмена. Предел одного снимка данных зданий — 64 MiB; превышение отвергается до изменения мира. [Проверки и точные границы](../reports/14_ui_and_god_replacement.md).

В God, «Ресурсы» → **«Наборы ресурсов»**: выберите имя и предметы из текущего каталога, задайте точные количества, сохраните набор. Загрузка меняет форму; применение требует подтверждения. Лимит — 32 набора, 64 вида/набор, 0–10000 каждого с учётом вместимости ядра. Меняются только перечисленные предметы, ноль очищает их запас. Значения видны до применения. Автоматической отмены нет; при необходимости заранее сохраните обратный набор. Наборы локальны, предметы мира синхронизируются штатно. Несколько ядер могут разделять общий запас команды.

## Сведения, слои и маршруты

Есть запасы ядра и наблюдаемое изменение во времени, данные энергосети, следующая волна и копирование состава. Составные юниты, особые точки появления и нестандартные модификаторы могут делать итоги волны неполными; окно показывает предупреждение.

Обычные фиксированные spawn учитываются в количестве и базовом здоровье; несколько групп одного типа суммируются. Для дополнительных сегментов и привязанного наземного выхода одного из нескольких ядер итог явно помечается частичным. Базовое здоровье не включает боевые множители.

В визуальных настройках ползунок видимости связей управляет штатной прозрачностью линий энергосети Mindustry и сохраняется в игровых настройках. Настройки приближения и отдаления мода применяются только при включённом пользовательском масштабе; после отключения возвращаются текущие штатные пределы камеры.

Локальные слои: сетка, линейка, полосы здоровья/боеприпасов, радиусы, энергия, рентген пола, скрытие изображения юнитов, дисплей поверх рамки, индикаторы построек. Скрытие не удаляет юнит из симуляции. Объём рисования ограничен; на удалённом сервере учитывается видимость. Другие моды с собственными группами рисования требуют отдельной проверки.

Для маршрутов выберите наземный, шагающий, морской или парящий профиль. Линии по соседним клеткам видны только владельцу мода. Это оценка от известных точек появления к ядрам, с четырьмя направлениями и ограниченным поиском. Игровой AI может выбирать другие цели, диагонали и пути. Изменения карты, туман и лимиты могут оставить часть маршрутов непостроенной.

Fog, освещение и затемнение границ являются **общими правилами мира**. Их меняет хост с подтверждением. God дополнительно предлагает числовые множители и настройки матча. Изменение множителя здоровья не гарантирует лечение существующих сущностей. Командные множители босса действуют отдельно.

## AI, игроки и юниты

Помощник запускается явно. Остановка — кнопкой/привязкой, при ручном движении, смерти, смене юнита/мира. Режимы: добыча с приоритетом, follow, курсор, круг, помощь планам, ремонт, атака выбранного вражеского блока. Это простое локальное управление; препятствия могут его остановить. Сервер сохраняет свои проверки предметов и строительства.

Список игроков: поиск, копирование имени, наблюдение, выбор команды и инструменты. Необязательный обмен подписью/редакцией по умолчанию выключен. Отсутствие ответа означает неизвестный статус, а не доказательство ванильного клиента. Старый протокол меток O279 не объявляется совместимым.

Хост может менять команду/тип тела, телепортировать, применять/снимать эффекты, создавать/удалять core shard и использовать штатные kick/ban/trace/admin. Входные данные и авторитетность проверяются повторно. Постоянный бан может затронуть общий IP. Свободный союзный юнит выбирается штатным запросом владения; удалённый сервер может отказать. Смена команд по кругу возвращает исходную команду при отключении; запуск босса останавливает циклы.

Управляемый распределитель — выключенная по умолчанию опция с перезапуском. Сохраняется штатная сериализация; передача направляется в соседнее союзное здание, принимающее предмет. У ванильного гостя новая кнопка не появляется. Возможен конфликт с модом, меняющим ту же фабрику.

Локальная JS-консоль доступна только в своей игре/у хоста, с явным подтверждением. Код обладает правами Java-мода и может менять файлы или заморозить игру. На чужой сервер он не пересылается. До восьми повторяющихся задач останавливаются отдельно/вместе; смена карты и потеря авторитетности отменяют их.

## «Босс-игрок» в God

1. Подключите минимум двух игроков. Выберите босса и разные команды босса/охотников.
2. Задайте подготовку, длительность, политику смерти/отключения. В боевых настройках выберите тело, эффекты, множители и стартовый ресурс/количество. Проверьте ядра и вместимость.
3. Можно сохранить именованный пресет. Загрузка только меняет подготовленные значения; применение начинается после запуска события. JSON импортируется/экспортируется через буфер. Файлового импорта пресетов пока нет.
4. Запустите и подтвердите участников. Ванильные сообщения объявляют подготовку, старт, события и результат; расширенный UI видит ведущий.
5. Смерть отдаёт победу охотникам либо создаёт тело после задержки и добавляет заданное время охотникам. Отключение: пауза до возврата/замены, победа охотников или ничья. Reconnect определяется UUID у хоста.
6. Пауза останавливает **часы события**, симуляция продолжается. Для замены выберите подключённого игрока и подтвердите. Возможны ручные победа стороны, ничья и отмена. Следующий запуск сохраняет счёт сессии.

После результата возвращаются изменённые командные множители и, если включено, команды. Стартовые ресурсы и произошедшее в мире не откатываются. Активный раунд и счёт не обещаются сохраняемыми через перезапуск приложения; загрузка карты сбрасывает событие, пресет остаётся локально.

## CLaJ, внешние backend-ы и updater

CLaJ требует совместимого внешнего relay прежнего протокола. Открытие окна не обращается к сети. Укажите доверенный адрес/порт и фактический порт собственного хоста, подтвердите создание и копируйте ссылку. Гостю нужен совместимый клиент/адаптер; обычному ванильному гостю подходит прямой IP/Steam. Комнаты закрываются отдельно/вместе либо при завершении хоста. Публичные сервисы и WAN не подтверждены. Транспорт пересылает TCP и не добавляет шифрование. Хост видит локальный адрес моста; бан по IP может затронуть нескольких гостей.

SlashJS/Darkdustry не являются ванильными API. Основной backend — собственный авторитетный хост. На неизвестный сервер JS/команды плагина автоматически не отправляются. Внешний backend без проверенной серверной реализации не объявляется поддержанным; используйте штатные средства совместимого сервера.

Канал релизов проекта пока не опубликован. Updater принимает явно указанный GitHub `owner/repository` и ищет JAR текущей редакции. Для скачивания нужны допустимый размер и SHA-256. Проверка, скачивание и импорт требуют отдельных действий; перед импортом повторно проверяется архив. Можно выбрать локальный JAR. После установки перезапустите игру. Исполняемый мод из неизвестного источника импортировать не следует.

## Данные, удаление, устранение проблем

Папку данных открывайте средствами игры. Обычно Windows использует `%APPDATA%\Mindustry`; Linux — `$XDG_DATA_HOME/Mindustry` либо `~/.local/share/Mindustry`. Эти пути определяет [Arc текущего build](https://github.com/Anuken/Arc/blob/7445105cd2/arc-core/src/arc/util/OS.java).

- `mods/scheme-size-shared-data/schematics` — копии схем;
- `mods/scheme-size-god/boss-presets` — пресеты God;
- `mods/scheme-size-plus/updates` / `mods/scheme-size-god/updates` — кандидаты обновлений;
- ключи `schemesize-*` и `schemetools-hud` сохраняются в настройках игры.

Удаление: выключите/удалите JAR штатным менеджером и перезапустите игру. Сохранения не удаляйте. Собственные схемы/пресеты можно оставить, экспортировать либо отдельно удалить после резервной копии. Общий каталог нужен оставшейся редакции. Не удаляйте всю папку `mods` или глобальные настройки.

Нет кнопки — проверьте build, включение мода/HUD, позицию и журнал. При двух редакциях интерфейс предоставляет God. Кнопка серая — проверьте свой хост, активный мир и цель. Отказ операции — проверьте координаты, туман, вместимость, очередь, масштаб и изменения после preview. Большие схемы размещайте участками; сложную картинку упрощайте. CLaJ не отвечает — закройте комнату и проверьте адрес/протокол; прямой хостинг остаётся доступным. Updater без релиза — проверьте источник и наличие опубликованного канала.

Настройки разбиты на «Экран / Панели / Ввод / Прочее». Кнопки не сжимают подписи привязок. У маршрутов «Пересчитать» включает линии; статус показывает процент чтения или причину отсутствия пути. [Актуальные кадры](../reports/14_ui_and_god_replacement.md).

## Группы юнитов, версия 0.3.0

«Юниты» по умолчанию открывает «На карте». Выберите команду сверху, затем один или несколько типов по плиткам с иконками и количеством. «Убить подходящих (N)» затронет всю подходящую группу. Снятие последнего типа даёт пустой фильтр, а не выбор всех.

«Выбрать рамкой» учитывает эти фильтры. В «Отдельные юниты» можно переключать отметки и убивать только отмеченных. При смене команды/типов индивидуальное выделение очищается. На новой карте фильтры сбрасываются на вашу команду и все типы. Пересчёт ширины и смена вкладок сохраняют фильтры; настройки создания находятся в «Создать».

Для прежнего глобального действия выберите «Все команды → Все типы → Убить подходящих». Команда/тип/управление перепроверяются при исполнении, новые спавны за время подтверждения не затрагиваются.

[Подробная публикация двух редакций в браузере](../docs/schemesize/publishing.md). [Иконка и исходник](artwork/README.md).

Действия игрока разделены на «Общее / Юнит / Права»; подсказки доступны по «?». Параметры сохраняются при смене вкладок. Предыдущие проверки этих действий: [№ 15](../reports/15_unit_death_and_player_ui.md).
