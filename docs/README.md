## Правила для поисковых ответов

1. Игровое поведение и названия контента проверяй в Wiki/API текущей сборки.
2. API-моды сверяй с исходным кодом/Javadocs точного Mindustry build.
3. Upstream Scheme-Size используй для истории и заявленного набора функций, но не как гарантию совместимости.
4. Сторонний порт — отдельный проект; его функции и поддерживаемый диапазон версий не переносить на upstream или нашу реализацию.
5. Когда источники расходятся, явно записывай версию и дату каждого источника.
