# Mindustry: обзор игрового цикла и мира

## Краткое определение

**[ФАКТ]** Mindustry сочетает фабричную автоматизацию, tower defense и RTS. Основные действия игрока — добывать ресурсы, строить цепи производства, снабжать боевые блоки, защищать базу, создавать/командовать юнитами и продвигаться по кампании. Доступны одиночная игра и сетевые кооперативные/PvP-режимы. [Страница Mindustry в Steam](https://store.steampowered.com/app/1127400/Mindustry/)

## Системная модель

```text
Карта и правила
  ├── окружение и залежи → добыча
  ├── ядро и строительные планы → размещение блоков
  ├── предметы/жидкости/payload → логистические сети
  ├── питание/тепло → доступность производства
  ├── рецепты → материалы, боеприпасы и юниты
  ├── давление врага → оборона и/или атака
  └── цель карты/сектора → захват, победа, исследование или следующий уровень
```

Это полезная модель для отладки: если блок не работает, сначала проверь его входы, маршрут входов, энергию/тепло, правила карты, состояние цели и доступность конечного выхода.

## Режимы и сценарии

- **Кампания**: прогресс через карту планеты и отдельные сектора; новые исследования расширяют доступные блоки/цепочки.
- **Survival/оборона**: игрок переживает атаки и улучшает базу между волнами.
- **Attack**: задача включает уничтожение вражеской базы; враг использует блоки и юниты.
- **Sandbox**: свободное строительство/эксперименты в пределах выбранных правил.
- **PvP и кооператив**: сетевое состояние и полномочия сервера становятся частью правил игры.
- **Редактор карты**: задаёт карту, цели, правила, спавны, блоки и сценарные элементы.

Доступность режимов, редакторных правил и блоков зависит от карты и настроек. Не переносить поведение sandbox в кампанию или сетевую игру без проверки.

## Планеты

### Serpulo

**[ФАКТ]** Историческая основная кампания с разветвлёнными секторами, цепями предметов/жидкостей, турелями и волнами. V8 переработала её карты и кампанийный прогресс, поэтому старые руководства V7 могут быть неточны. Новая система межсекторной доставки использует посадочные площадки для приёма ресурсов. [Заметки V8 Build 147](https://store.steampowered.com/news/posts/?appgroupname=Mindustry&appids=1127400&enddate=1744600127&feed=steam_community_announcements)

### Erekir

**[ФАКТ]** В V7 добавлена отдельная планета со своим tech tree, блоками, юнитами, более линейной кампанией и полноценными атакуемыми вражескими базами. В её системах заметны payload, ducts и тепло. V8 также добавила/изменила элементы контента и логики, поэтому подробные свойства надо сверять с актуальной Wiki. [Официальные заметки Mindustry 7.0](https://steamcommunity.com/games/1127400/announcements/detail/3415444546227810672) · [Вики](https://mindustrygame.github.io/wiki/)

Не считать планеты только разными наборами текстур: правила, рецепты, транспорт и деревья прогресса различаются.

## Базовые сущности

| Сущность | Роль |
|---|---|
| Tile / клетка | позиция карты, рельеф и место размещения |
| Block | тип здания или структуры, его свойства и правила размещения |
| Building | конкретный блок, установленный на карте, с состоянием и инвентарём |
| Core | основное хранилище команды и критическая цель |
| Item / Liquid | переносимые ресурсы и продукты |
| Payload | крупный перемещаемый объект, блок или юнит |
| Unit | действующий объект, который может двигаться, атаковать, строить или переносить |
| Sector | кампанияльная территория/карта, привязанная к планете |
| Rules | параметры режима и карты: лимиты, команды, победа, волны, стоимость и т. п. |
| Schematic | сохраняемая схема размещения блоков, используемая для планирования/постройки |

Различие `Block` и `Building` особенно важно для API и Logic: первое — тип, второе — экземпляр на карте. [Logic glossary](https://mindustrygame.github.io/wiki/logic/1-glossary/) · [Rules API](https://mindustrygame.github.io/docs/mindustry/game/Rules.html)

## Инварианты для анализа

- Игровой объект может быть недоступен, уничтожен или `null`; сначала проверяй существование.
- Возможности зависят от команды, режима, команды игрока, правил, tech unlock и server authority.
- Встроенная Mindustry Logic, JavaScript mod scripting и Java API — разные уровни доступа и исполнения.
- Если обсуждение касается рецептов, лимитов и точных статов, указывай planet и build.
