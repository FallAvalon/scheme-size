# Бой, юниты и кампания

## Оборона

- Турели требуют подходящего боеприпаса или типа ресурса; некоторые требуют энергию, жидкость/охлаждение либо иные условия.
- Стены замедляют/блокируют движение и прикрывают ключевые блоки, но их материал, размер, здоровье и уязвимости отличаются.
- Поддерживающие блоки лечат, ремонтируют, ускоряют или защищают — учитывай радиус действия и питание.
- Позиционирование важно: дальность, сектор обзора, тип целей и снаряд определяют реальную эффективность турели.
- Волновой режим и attack mode имеют разные цели: пережить таймер/волны против уничтожения вражеского ядра/базы.

## Юниты

Юнит — объект мира, тип юнита — определение его характеристик. Юниты могут быть боевыми, поддерживающими, строительными, разведывательными или транспортными. Способ производства зависит от планеты: фабрика/реконструктор или payload-сборка. В V8 есть стойки и команды для патрулирования, удержания огня и очередей приказов; изменённый pathfinding должен проверяться на текущем build. [Заметки V8 Build 147](https://store.steampowered.com/news/posts/?appgroupname=Mindustry&appids=1127400&enddate=1744600127&feed=steam_community_announcements)

Программное управление юнитом возможно через вручную заданные RTS-команды или логику процессора, если правила разрешают `logicUnitControl` и нужные виды строительства/разбора. Эти разрешения — отдельные поля правил карты. [Rules API](https://mindustrygame.github.io/docs/mindustry/game/Rules.html)

## Кампания и сектора

- Планеты имеют собственные tech tree и кампанийные карты.
- Сектор содержит одну карту и задаёт спавны, правила, победные условия, сложность, стартовые ресурсы, погоду и разрешённые блоки.
- Возможные игровые цели: пережить заданные волны, захватить территорию, уничтожить вражескую базу или выполнить цель сценария.
- Занятые территории и межсекторная логистика связывают разрозненные карты в кампанийную сеть.
- Секторная прогрессия часто даёт доступ к новым ресурсам/блокам, что делает кампанию зависимым графом unlocks.

Точные параметры сектора бери из его `SectorPreset`, карты или актуальной внутриигровой записи. [SectorPreset](https://mindustrygame.github.io/wiki/Modding%20Classes/SectorPreset/) · [SectorInfo API](https://mindustrygame.github.io/docs/mindustry/game/SectorInfo.html)

## Изменения V8

Официальные заметки первого beta Build 147 включали:

- переработку кампании Serpulo и пользовательские карты;
- кампанийные модификаторы сложности;
- требование посадочной площадки для получения ресурсов от launch pad;
- функциональные улучшения Interplanetary Accelerator;
- новые стойки и приказы юнитам, включая patrol/hold fire/queue;
- изменение pathfinding;
- новые функции Logic и World Processor.

Официальная текущая Wiki обозначает Build 160.7 как latest reference build в момент исследования. Далее вышли поправки к серверной работе команд/стоек и к логике статусов. Сверяй весь список изменений по [релизам игры](https://github.com/Anuken/Mindustry/releases).

## Сетевые границы

В сетевом режиме сервер — источник истины для команд, правил и привилегий. UI клиента может предложить действие, но не должен сам объявлять его разрешённым. Для модов, меняющих состояние мира, разделяй:

| Сценарий | Где проверяется разрешение |
|---|---|
| локальная подсветка/информация | клиентская настройка |
| редактирование локальной схемы | клиентский файл/встроенный API |
| постройка в мире | штатные игровые проверки и правила карты |
| spawn/fill/teleport/rules | серверная проверка команды и полномочий |
| отображение/настройки выделенного сервера | server-safe UI/command path |
